# Prática de Git e TypeScript - Aula 03

Este repositório é um esqueleto de aplicativo React Native propositalmente escrito em JavaScript. 

## Sua Missão:
1. Clonar este repositório.
2. Criar uma branch com seu nome (`feature/seu-nome`).
3. **Conflito Proposital:** No arquivo `src/App.js`, altere a constante `APP_TITLE` para incluir seu nome (ex: `"App de Tarefas - Marjore"`).
4. Fazer commit e push da sua branch.
5. Abrir um Pull Request (PR) para a branch `main`.
6. Revisar o PR de um colega.
7. (Bloco 3 e 4) Refatorar os arquivos `.js` para `.ts` / `.tsx`, adicionando interfaces, tipagem de props e null safety.
